STRIP STUDIO — INSTALLABLE LOCAL APP

FIRST RUN
1. Extract this folder to a normal folder on your Windows computer.
2. Double-click Start-StripStudio.bat.
3. Open http://localhost:8080 in Microsoft Edge.

INSTALL AS AN APP IN MICROSOFT EDGE
1. Start the local app with Start-StripStudio.bat and visit http://localhost:8080.
2. Wait a few seconds for the app to finish loading, then look at the right side of Edge's address bar for the Install app icon. If it does not appear immediately, refresh the page once.
3. Select Install. Edge opens its own installation dialog. Choose the available options to pin Strip Studio to the taskbar and/or Start menu, create a shortcut, or start it when you sign in (the options shown depend on your Edge/Windows version).
4. Keep the extracted StripStudio_Local folder in place. The local server must be started for the app to load. Run Start-StripStudio.bat whenever the server is not running.

OFFLINE / LOCAL BEHAVIOR
- The app shell is cached for offline use, but the local server still needs to be running for the localhost app to open reliably.
- The Phomemo D30 Bluetooth feature works from localhost in a supported browser. Bluetooth and the printer must be available.
- This app does not upload label data to a cloud service.

APP FEATURES
- Installable PWA manifest and app icons.
- Local service worker cache for the app files.
- Existing barcode design, queue, canvas editing, and printing features remain available.

NOTE
The exact install and pinning choices are controlled by Microsoft Edge and Windows and may differ by version. The install icon appears only when Edge considers the app installable.
